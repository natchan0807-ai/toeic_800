## 技術判断

npm registryはDNS解決不可、ネットワーク制限のため依存を取得できない。React/Viteを基本案として確認したが、この環境で再現・起動できるTypeScript＋標準DOMのSPAに変更する。IndexedDB、Service Worker、Node標準テストを使う。利用可能なローカルTypeScriptコンパイラをライセンス付きで同梱してオフラインでビルド可能にする。外部AI API不要。配信先は利用者が選べる静的ホスト。

教材難度・出題配分・復習間隔・証拠10件の閾値は学習設計上の仮設定。520点から技能別弱点を推測しない。教材はオリジナルでTOEIC全範囲の対策ではない。
